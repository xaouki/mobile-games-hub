# Chaouki Eye 📷

A clean Android camera app with front/back camera switching and local video recording.

## Included
- Front and rear camera
- Video recording to `Movies/Chaouki Eye`
- Simple dark interface
- Camera permission handling
- CameraX architecture
- Google Mobile Ads SDK dependency prepared for future AdMob monetization
- GitHub Actions workflow that builds a debug APK

## Build
Run the **Build Chaouki Eye APK** workflow from GitHub Actions. The generated APK is uploaded as the `Chaouki-Eye-debug` artifact.

## Monetization before release
Android apps use **Google AdMob**, not AdSense directly. Add your own AdMob App ID and ad unit IDs, publish a privacy policy, implement required consent flows, and follow Google's current publisher policies before enabling production ads.
